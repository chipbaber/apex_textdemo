### Database User and Table Setup

Connect to the Autonomous Database as `ADMIN` and run the following statements to create the `PLAYERS` database user. Replace the password placeholder with a strong, unique password before executing; do not commit the real password to this file. If `PLAYERS` already exists, do not run `CREATE USER` again.

```sql
CREATE USER players IDENTIFIED BY "<replace-with-strong-unique-password>"
    DEFAULT TABLESPACE data
    QUOTA 20M ON data;
```

Grant `CONNECT` and `RESOURCE` to `PLAYERS`. `CONNECT` includes `CREATE SESSION`, and `RESOURCE` includes `CREATE TABLE`, so separate grants of those privileges are not needed here. `RESOURCE` also includes other object-creation privileges; the `DATA` tablespace quota allows the table and its primary-key index to allocate space.

```sql
GRANT CONNECT TO players;
GRANT RESOURCE TO players;
```

Connect as `PLAYERS` before running the following `TEAMSTATS` SQL in SQL Workshop / SQL Commands. These baseline grants do not enable Database Actions or ORDS web access; configure that separately if needed.
